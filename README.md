# 信託服務費試算

輸入土地融資、建築融資的金額與期數，自動帶出對應費率，算出土融費用、建融費用、額外工程查核費用與合計服務費，並列出工程查核次數。

整個工具只有一個 `index.html`，不需要安裝、不需要網路，資料也不會傳到任何地方。

## 使用方式

1. 下載 `index.html`（點檔案後按右上角的 Download，或 Code → Download ZIP 後解壓縮）。
2. 用瀏覽器（Chrome、Edge、Safari）直接雙擊開啟。
3. 輸入金額（單位：元，例如 `290000000` 代表 2 億 9,000 萬，欄位下方會顯示換算結果）、選擇期數，結論會即時更新。

## 計算規則

所列金額均含稅。

### 土地融資

| 融資金額 | 24 個月 | 36 個月 |
|---|---|---|
| 未達 5000 萬 | 2‰ | 2.5‰ |
| 5000 萬以上－未達 1 億 | 1.5‰ | 2‰ |
| 1 億以上－未達 1.5 億 | 1.2‰ | 1.8‰ |
| 1.5 億以上－2 億以內 | 1‰ | 1.5‰ |
| 超過 2 億部分加收 | 0.5‰ | 0.5‰ |

- 超過 2 億：前 2 億按「1.5 億以上－2 億以內」費率，超過部分按 0.5‰。
  例：2 億 9,000 萬／24 個月 = 2 億 × 1‰ + 9,000 萬 × 0.5‰ = 245,000 元。
- 無開立信託專戶、無孳息扣繳各可打九折，兩項不累計（只打一次）。
- 低消 60,000 元：折扣後未達 6 萬以 6 萬計。
- 金額為 0 視為沒有土融，費用 0 元。

### 建築融資

| 融資金額 | 24 個月費率 | 基本查核次數 | 無期限費率 | 基本查核次數 |
|---|---|---|---|---|
| 未達 5000 萬 | 3‰ | 3 | 4‰ | 8 |
| 5000 萬以上－未達 1 億 | 2.5‰ | 5 | 3.5‰ | 10 |
| 1 億以上－未達 1.5 億 | 2.2‰ | 7 | 3.2‰ | 12 |
| 1.5 億以上－2 億以內 | 2‰ | 10 | 3‰ | 15 |
| 超過 2 億部分加收 | 0.5‰ | － | 0.5‰ | － |

- 超過 2 億的算法同土融；基本查核次數沿用「1.5 億以上－2 億以內」級距。
- 九折優惠不適用於建融。

### 額外工程查核

| 地區 | 每次費用 |
|---|---|
| 北北基地區 | 10,000 元 |
| 桃竹苗中及宜蘭 | 15,000 元 |
| 其他地區（不含離島） | 20,000 元 |

離島地區另計，不在試算範圍。

### 合計

合計服務費 = 土融費用 + 建融費用 + 額外工程查核費用

工程查核總次數 = 基本查核次數 + 額外查核次數

## 注意

試算結果僅供參考，實際報價以正式文件為準。
